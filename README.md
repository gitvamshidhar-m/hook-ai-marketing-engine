# Hook AI — The Angle Discovery Engine for Marketers

An AI-powered digital marketing SaaS that finds the **psychological angles your competitors are missing**, generates **CTR-scored hooks** for every channel (ad headline, email subject, YouTube title, blog H1), frames a **USP**, and grades the whole campaign with a **0–100 Campaign Health Score** — all in seconds.

> **Live:** https://hook-ai-marketing-engine.vercel.app · **Stack:** Next.js 16 (App Router) · React 19 · TypeScript · Tailwind v4 · Supabase (auth + Postgres) · Razorpay (billing) · Groq/Gemini (AI)

---

## Why this project exists

Built as a self-shipped, end-to-end product — not a demo — with real users, real auth, real payments, real analytics, and an AI-provider abstraction layer. It's the "full marketing funnel" story in one repo: **research → strategy → content → launch → analytics → optimize.**

## Features

### Core engine
| Feature | What it does |
|---|---|
| **10 Psychological Angles** | Maps any topic to curiosity, loss aversion, contrarian, authority, social proof, data, story, specificity, identity, misdirection — each with the "why it works". |
| **CTR Prediction Score** | Every hook gets a 0–100 score and its psychological trigger, so A/B tests run on judgment, not guesses. |
| **Competitor Gap Scanner** | Paste (or **import a CSV of**) competitor headlines → finds the angles they're all ignoring. |
| **Campaign Health Score** | One 0–100 grade weighing angle diversity, hook strength, channel coverage, readability, positioning, and white space — with a fix-it checklist. |
| **Angle Coverage Meter + Heatmap** | Live breakdown of all 10 angles vs competitor saturation — see your blue ocean. |
| **Channel-Native Hooks** | Ad headlines, email subjects, YouTube titles, blog H1s — formatted where they'll run. |
| **Try Harder** | Regenerate hooks that deliberately avoid psychologies you already used. |
| **AI Tools Panel** | Improve a hook (4 modes), explain *why* it works, mine voice-of-customer, generate email series, 14/21-day content calendars, landing pages, personas, SEO meta, budget allocation, brand voice, platform export, A/B tracker, readability checker. |
| **Campaign Studio** | One click → a complete marketing plan: hooks, health score, budget split, channel strategy, 7-day content calendar, funnel fit, targeting, and KPIs. |

### Product / growth
| Feature | What it does |
|---|---|
| **Accounts** | Email/password auth (Supabase Auth), session cookies, profile + credit balance. |
| **Credits & billing** | 10 free credits on signup; Razorpay checkout + signature-verified top-ups (Starter 50 / Pro 250). |
| **Referral program** | Each user gets a `?ref=` link — when a friend signs up, **both earn +5 credits**. |
| **Saved projects** | Campaigns sync to your account, plus local browser storage. |
| **Community board** | `/community` shows the highest-scoring hooks generated by real users. |
| **Shareable campaigns** | Publish any campaign to a persisted `/s/<slug>` URL — stored in Postgres, recruiter-clickable, with SEO metadata. |
| **Analytics dashboard** | `/analytics` shows total runs, AI vs engine, avg best-score, avg **health score**, and a 14-day trend. |
| **Admin dashboard** | `/admin` (role-gated) shows platform stats, the payments ledger, and community-feed moderation. |
| **Exports** | CSV, Google-Sheets-ready copy, branded print-to-PDF campaign report. |
| **Rate limiting** | Sliding-window limiter on all AI endpoints (429 on abuse). |
| **Health endpoint** | `/api/health` reports AI + Supabase status for monitoring. |

## Architecture

```
Browser ──▶ Next.js App Router (Vercel)
             │  ├─ /api/analyze        → validate → rate-limit → AI | engine fallback → credit spend
             │  ├─ /api/campaign       → one-shot full campaign plan + health score
             │  ├─ /api/ai-tools       → 14 AI tools, same pipeline
             │  ├─ /api/adcopy         → platform ad copy
             │  ├─ /api/auth/*         → Supabase Auth (signup/login/logout/session)
             │  ├─ /api/projects       → per-user saved campaigns (Postgres + RLS)
             │  ├─ /api/billing/*      → Razorpay order + signature-verified credit top-ups
             │  ├─ /api/shares         → persisted /s/<slug> campaign links
             │  ├─ /api/referral       → referral code + earned-credit stats
             │  ├─ /api/admin/*        → role-gated platform stats + moderation
             │  ├─ /api/health         → observability
             │  └─ proxy.ts            → session refresh on every request
             ▼
   lib/  ai.ts (Groq + Gemini, provider abstraction, graceful fallback)
          engine.ts  (deterministic no-API-key mode)
          aitools.ts (13 AI marketing tools)
          campaign.ts (one-click campaign plan builder)
          psych.ts   (hook → psychology classifier, shared AI/engine)
          health.ts  (Campaign Health Score computation)
          credits.ts (atomic credit spend via Postgres RPC)
          admin.ts · shares.ts · referral.ts
          ratelimit.ts · csv.ts · export.ts · supabase.ts · razorpay.ts · analytics.ts
supabase/schema.sql + schema_v2.sql  # tables + RLS + RPC (run once)
tests/eval_api.py                    # automated LLM eval suite
e2e/ · playwright.config.ts          # Playwright smoke tests
.github/workflows/ci.yml             # lint + typecheck + build + e2e
```

**AI strategy:** an abstraction layer that tries the configured provider (Groq's `llama-3.3-70b-versatile`, Gemini fallback), validates the response shape, and falls back to a deterministic engine so the product never hard-fails. Every AI run spends one credit atomically via a Postgres RPC.

## Local setup

1. `npm install`
2. Copy `.env.example` → `.env.local` and add keys (optional — the engine works without AI keys):
   - **Groq** (free): https://console.groq.com/keys → `GROQ_API_KEY`
   - **Gemini** (free): https://aistudio.google.com/apikey → `GEMINI_API_KEY`
3. `npm run dev` → http://localhost:3000

### Optional: Supabase (auth, projects, analytics, community)
1. Create a free project at https://supabase.com
2. Run **`supabase/schema.sql`** in the SQL editor (creates `profiles`, `projects`, `community_hooks`, `payments`, `spend_credit` RPC + RLS policies).
3. Add env vars:
   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### Optional: Razorpay billing (India)
1. Create a free account at https://dashboard.razorpay.com (or activate your API keys under Settings → API Keys).
2. Add env vars: `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET` (optionally `RAZORPAY_STARTER_AMOUNT` / `RAZORPAY_PRO_AMOUNT` in paise).
3. Test payments use Razorpay test cards (e.g. `4111 1111 1111 1111`); no webhook setup required — credits are granted after client-side signature verification.

## Testing / evals

Automated evaluation suite that hits the **deployed** API with known prompts and asserts output quality:

```bash
python tests/eval_api.py          # defaults to the live Vercel URL
HOOKAI_BASE=http://localhost:3000 python tests/eval_api.py   # against local dev
```

This doubles as CI for LLM outputs — a reliable, cheap way to catch prompt regressions.

### E2E + CI

- **Playwright** smoke tests (`e2e/`) run the engine fallback end-to-end (no API keys needed): home tool generates hooks, Campaign Studio loads.
- **GitHub Actions** (`.github/workflows/ci.yml`) runs `lint`, `typecheck`, `build`, and Playwright on every push/PR.

```bash
npm run typecheck    # tsc --noEmit
npm run test:e2e     # Playwright (npx playwright install first)
```
